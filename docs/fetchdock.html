FetchDock 使用文档

Windows 多线程下载器，可将 Edge 或 Chrome 中的网盘任务推送到桌面程序，支持断点续传和任务排队。

本页目录 安装 使用 文件校验

选择下载包 · Windows x64

  • 普通安装版提供 下载 EXE · 下载安装 ZIP。运行 EXE 后从开始菜单打开，默认目录为 %LOCALAPPDATA%\Programs\FetchDock。
  • 便携版提供 下载便携 ZIP。完整解压后运行 FetchDock.exe，依赖文件保留在同一目录。
  • 浏览器扩展随桌面包提供，位于 browser_ext。也可 单独下载扩展 ZIP 后解压。

连接 Edge 或 Chrome

  1. 在 edge://extensions/ 或 chrome://extensions/ 打开开发人员模式，加载解压后的扩展文件夹，选择含 manifest.json 的目录。
  2. 在扩展选项复制启动器注册命令，在 PowerShell 中运行。若用便携版或自选安装目录，把命令中的程序路径改为实际的 FetchDockNative.exe 路径。
  3. 重新加载扩展并刷新网页，点击「启动 / 连接下载器」。连接成功后，即可将可用的网盘任务推送到桌面程序。

移动程序目录后需要重新注册。普通版与便携版共用当前用户的 %APPDATA%\tdm_downloader 设置与未完成任务。

版本与文件校验

从 2.0.2 发行页 下载 SHA256SUMS.txt。在下载目录运行以下 PowerShell 命令，将结果与清单里同名文件的 SHA-256 比较。

Get-FileHash -Algorithm SHA256 .\FetchDock-2.0.2-windows-x64-setup.exe

安装 EXE 未进行代码签名。原发行清单用于校验它列出的附件。安装 ZIP 内包含安装 EXE，可解压后校验其中的 EXE。FetchDock 的对应源码及许可证见 2.0.2 源码 ZIP。
