清影 使用文档

用本地文件、视频直链或自备的 MacCMS 片源播放视频，管理收藏和观看历史。

按设备下载

Android 7.0 及以上

下载 APK，在 Android 设备上打开 APK 完成安装。手机端支持离线缓存。

Windows 10 / 11 x64

下载 EXE · 下载安装 ZIP。ZIP 需要先解压。运行 EXE 后，从开始菜单打开清影。

添加内容并播放

  1. 公开版首次打开时片源为空。可以打开一个本地视频，输入 HTTP 或 HTTPS 视频直链，或添加自己使用的 MacCMS 接口。
  2. 使用 MacCMS 片源时，可搜索影片并在详情页选择剧集和可用线路。
  3. 用收藏和观看历史管理片库。可用线路与播放稳定性取决于片源和网络。

公开版的原片源账号、互动和云同步不可用。后台缓存、画中画与屏幕亮度控制由 Android 端提供。

版本与文件校验

从 Android 发行页 或 Windows 发行页 下载 SHA256SUMS.txt。在下载目录运行以下 PowerShell 命令，将结果与清单里同名文件的 SHA-256 比较。

Get-FileHash -Algorithm SHA256 .\Qingying-1.0.0-windows-x64-setup.exe

命令以 Windows 安装包为例。校验 APK 或 ZIP 时，把文件名换成实际下载的文件名，并使用对应平台的清单。
