GameFixKit 使用文档

先以只读方式排查 Windows 游戏运行环境，再按提示决定是否执行修复。

安装 · Windows 10 / 11 x64

下载 EXE · 下载安装 ZIP。ZIP 需要先解压，再运行其中的 EXE。安装包自带 Python 和 Tk，安装后从开始菜单打开。

先体检，再确认修复

  1. 进入「环境体检与修复」，先运行只读体检，查看与游戏故障相关的运行库、系统服务等检查结果。
  2. 阅读选中项目的修复说明，再决定是否执行。部分操作需要管理员权限，请按应用提示确认。
  3. 如需撤销设置变更，先在备份记录中核对对应操作和可回滚范围。运行库安装与网络栈重置无法由应用自动撤销。

商品监控功能需要另行运行本机服务。环境体检可以独立使用。

版本与文件校验

从 0.1.1 发行页 下载 SHA256SUMS.txt。在下载目录运行以下 PowerShell 命令，将结果与清单里同名文件的 SHA-256 比较。

Get-FileHash -Algorithm SHA256 .\GameFixKit-0.1.1-windows-x64-setup.exe

安装包未进行代码签名。0.1.1 发行记录包含安装、启动、只读扫描、自检和卸载的验证范围。
